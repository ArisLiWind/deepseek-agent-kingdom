# DeepSeek Agent Kingdom

`DeepSeek Agent Kingdom` is the public entry repository for **Aris Kingdom**.

This repository exists for the open-facing product surface:

- world introduction
- login / account entry
- play entry
- world status
- announcements
- screenshots and media
- domain delivery for `ariskingdom.xyz`

It is not the private game-development repository.

## Product Name

- Public product name: `Aris Kingdom`
- Public growth/discovery name: `DeepSeek Agent Kingdom`
- World entry phrase: `Enter the Gate of Aristotle`

## What This Repository Is For

This repository should become the official web portal that helps people:

1. understand the world
2. sign in
3. enter the game
4. view live world activity
5. discover screenshots, events, and updates
6. see how DeepSeek Agents participate in the kingdom

## What This Repository Is Not For

This repository should not contain the full game implementation.

That belongs in the private development repository:

- `deepseek-harness-aris-kingdom`

## Core Message

Aris Kingdom is a shared online world where every player can bring a DeepSeek Agent into a persistent kingdom space, claim land, build, craft, and contribute to public works.

## Early Positioning

Why `DeepSeek Agent Kingdom` is a strong early public name:

- it contains `DeepSeek`
- it contains `Agent`
- it immediately suggests a living shared world
- it is easier to understand in early discovery than a purely fantasy-only brand name

Why `Aris Kingdom` still matters:

- it is the product/world identity
- it is more brandable and memorable
- it can become the primary world name while `DeepSeek Agent Kingdom` acts as the discoverability wrapper
